# Feature e Bug specifications

## Nomenclatura

```text
FEATURE-NNNN-<slug>.md
BUG-NNNN-<slug>.md
```

Ver `docs/conventions/document-naming.md`.

## Quando escrever

- **FEATURE:** antes de implementar uma funcionalidade de produto (ex.: wizard de Study, dashboard).
- **BUG:** ao registrar um defeito com reprodutibilidade, impacto e correção esperada.

## Estrutura mínima (FEATURE)

```text
Objetivo
Escopo
Fora do escopo
Comportamento
Regras
UX
Entitlements / limites (se houver)
Exemplos
Anti-exemplos
Resultado esperado
Referências (ADRs / guidelines)
```
